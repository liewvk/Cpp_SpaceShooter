# C++ Space Shooter

A game programming project exploring C++ game development concepts from Chapter 10.

## Project Overview

This is a space shooter game implemented in C++ as part of learning game programming fundamentals.

## Build

This project uses CMake for building.

```bash
mkdir build
cd build
cmake ..
make
```

## Technology Stack

- **Language**: C++ (97.3%)
- **Build System**: CMake (2.7%)
